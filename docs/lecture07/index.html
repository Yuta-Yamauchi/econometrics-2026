100人の区間は0を含み，10,000人の区間は0を含まない。10,000人の例で候補に残る効果は，約0.006〜0.014点である。

分析者が補習1時間当たり1点以上を実質的に大きい効果と考える場合，この区間の上端も1点を下回る。効果の大きさは，区間を分析者の基準と比べて判断する。

モデルと計算の対応

正規回帰モデルでは，傾きの推定量は N(β₁, σ² / Sₓₓ) に従う。未知の σ を残差から求めた sᵤ に置き換えた統計量は，帰無仮説の下で自由度 n − 2 の t 分布に従う。ここではこの分布の分位点を臨界値に使う。

n = 100 の最初の標本は講義スライドと共通である。その後は，同じ X を保って誤差を生成する。信頼水準を変えたときは同じ標本を使い，標本サイズを変えたときは最初の標本から始める。

区間幅の比較では，切片2・傾き1.5の直線に直交する残差を用いる。標本サイズの比較は sᵤ と Sₓₓ / n，残差の比較は X，X の比較は観測数と残差をそろえる。各図の端点の傾きは，標本の中心を通る直線として描く。
