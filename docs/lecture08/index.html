母集団と計算式

平均曲線は第2回と共通である。第8回の設定に合わせ，誤差を U = 10(E − 1)，E ∼ Exp(1) とし，X と独立に生成する。Exp(1) は平均1の指数分布である。得点は Y = m(X) + U で生成する。

短時間・長時間に多い設定では，第2回と同じく，平均2・8，標準偏差3の正規分布を0〜10で切断する。母集団の線形射影係数は，選択した X の分布で期待値を計算して求める。

β₁ = Cov(X, m(X)) / Var(X)，　β₀ = E[m(X)] − β₁ E[X]

標準誤差は，第8回スライドと同じHC0を使う。各観測の回帰残差を ûᵢ = Yᵢ − β̂₀ − β̂₁Xᵢ，Sₓₓ = ∑ᵢ(Xᵢ − X̄)² とすると，次の式になる。

se(β^1)=∑i(Xi−X¯)2u^i2SXX

傾きの分布に重ねる青の正規曲線は，線形射影係数を中心とし，母集団のモーメントから求めた漸近分散を標本サイズで割った分散を使う。区間の幅には，各標本のHC0標準誤差を使う。

標本はブラウザー内で生成する。同じ設定では同じ標本列を再現し，信頼水準を変えたときは同じ標本から区間を計算し直す。分布・標本サイズを変えると1回目から始める。
